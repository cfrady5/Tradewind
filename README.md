# Tradewinds — tradewindai.com rebuild

The public website for **Tradewinds** — the Department of War's ecosystem for discovering, assessing and acquiring AI, digital and data-analytics solutions (CDAO).

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Motion · Supabase.

```bash
npm install
npm run dev
```
